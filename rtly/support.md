# RTLy support

Something broken on a supported site, or want a new site supported? Email **ah.sawahel+support@gmail.com** — or use "Report a broken site" / "Request this site" in the RTLy menu, which fills in the details for you (site name, RTLy version, browser — never chat text).

## Supported sites (RTLy 1.0)

- chatgpt.com
- claude.ai
- gemini.google.com
- chat.deepseek.com
- www.perplexity.ai
- grok.com
- copilot.microsoft.com
- aistudio.google.com
- notebook.google.com
